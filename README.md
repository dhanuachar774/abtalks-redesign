# ABTalks – 60 Day Coding Challenge Redesign

## 🚀 About the Project

ABTalks is a 60-day coding challenge platform where students build something every day and share public proof of their progress.

This project redesigns the ABTalks experience with a modern, engaging interface focused on consistency, visibility, and public proof of work.

## 🎯 Problem

Students often learn coding but struggle to stay consistent and show their progress to recruiters.

ABTalks addresses this by encouraging students to:

- Build something every day
- Maintain a coding streak
- Commit their work to GitHub
- Share their progress on LinkedIn
- Build a visible public proof of work

## ✨ Key Features

- 🔥 60-day coding challenge
- 💻 Daily build and GitHub proof
- 💼 LinkedIn progress sharing
- 📊 Streak and progress section
- 🏆 Community leaderboard
- 🔐 Login and signup functionality
- 👤 User name displayed after login
- 🚪 Logout functionality
- 📱 Responsive design
- ✨ Interactive hover effects
- 🚀 Live deployment using Vercel

## 🎨 Redesign Highlights

The redesigned ABTalks homepage focuses on making the challenge feel motivating, clear, and community-driven.

### Improvements
